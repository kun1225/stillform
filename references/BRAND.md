# Brand Guideline

## 1. Overview（我是誰 + 做什麼）

我們是誰：
Stillform 是一個專注於工作效率、美觀設計的硬體品牌，目標打造專注、效率、美觀、美好生活的產品形式。

我們提供什麼（產品 / 服務）：
結合鬧鐘與蕃茄鐘功能的實體計時器，主打精緻工藝與乾淨的使用體驗。

網站的目標（轉換 / 展示 / 收單）：
展示產品質感與品牌理念，引導訪客加入候補名單（waitlist）。

---

## 2. Target Audience（我幫誰 + 解什麼問題）

目標使用者：
注重效率與美感的遠端工作者，習慣打造高品質桌面環境，對工具的設計感有要求。

他們的主要問題：
市面上的蕃茄鐘要嘛只是 App、要嘛是廉價實體計時器，放在桌上破壞整體質感，難以長期使用。

他們想要的結果：
一個真正好看、好用，值得放在桌上的專注工具——既能幫助管理時間，也讓工作環境更有質感。

不服務的對象（可選，但很有用）：
只在乎功能、不在意外觀的使用者；純粹想用免費 App 管理時間的人。

---

## 3. Core Message（最重要）

一句話價值主張（Tagline）：
專注與美觀並存。

### 為什麼選我？（1–2 點）：

- 設計語言極簡克制，放在任何桌面都不違和，是少數「值得陳列」的生產力工具。
- 鬧鐘與蕃茄鐘整合於單一實體裝置，減少手機干擾，讓專注回到物理世界。

## 4. Tone of Voice（怎麼說）

語氣關鍵字（3 個）：
沉靜、精緻、克制

寫作規則：

- 用詞偏好：短句、名詞性語句、具體的感官描述（觸感、比例、留白）
- 避免用詞：「革命性」、「顛覆」、「賦能」、「一站式」等過度行銷用語
- 語氣風格：像一本好的產品設計書，說得少，但每一句都有重量；Apple 式極簡加上一點手工感的溫度
